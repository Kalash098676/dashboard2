# House Rocket Portfolio Dashboard

## Overview

The **House Rocket Portfolio Dashboard** is a Power BI data analytics project designed to analyze real estate properties and identify useful trends, patterns, and investment opportunities.

The dashboard provides interactive analysis based on **time, property features, location, historical trends, and outliers**.

## Dashboard Pages

### 1. Main

The main page provides navigation to the different sections of the dashboard:

* Time Analysis
* Feature Analysis
* Geolocation and Historical Analysis
* Outlier Analysis

### 2. Time Analysis

Analyzes property trends over time, including:

* Price trends
* Property sales/listing patterns
* Yearly and monthly comparisons

### 3. Feature Analysis

Analyzes how property characteristics influence prices, such as:

* Bedrooms
* Bathrooms
* Floors
* Property size
* Other house features

### 4. Geolocation and Historical Analysis

Provides location-based insights and historical comparisons to understand:

* Property distribution by location
* Price differences between areas
* Historical market trends

### 5. Outliers

Identifies unusual properties or values that differ significantly from normal patterns, helping detect:

* Extremely high-priced properties
* Extremely low-priced properties
* Unusual property characteristics

## Tools & Technologies

* **Power BI** – Dashboard and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculations and measures
* **CSV/Excel** – Data source

## Objectives

* Understand real estate price trends.
* Identify important property features affecting prices.
* Compare property prices across locations.
* Analyze historical housing patterns.
* Identify potential outliers.
* Support data-driven real estate investment decisions.

## Key Insights

The dashboard helps users understand **when, where, and why property prices differ**, making it easier to identify market patterns and potential investment opportunities.

## Project Purpose

This project demonstrates the practical use of **Business Intelligence and Data Analytics in the real estate domain**, converting raw housing data into meaningful and interactive insights using Power BI.
